# BMS Pet Project — Учебная документация

Добро пожаловать в документацию учебного проекта по интеграции систем кондиционирования (VRF/FCU) в единую систему управления зданием (BMS).

## Цель проекта

Смоделировать полный цикл работ системного интегратора BMS **без физического оборудования**:

1. Эмуляция устройств (Modbus TCP / BACnet/IP).
2. Проектирование «карты точек» (Points Schedule).
3. Разработка сервиса-шлюза (опрос, логика, API).
4. Веб-интерфейс для мониторинга и управления.
5. Документирование по стандартам, приближенным к реальным объектам.

## Структура документации
